# Tabs

Два переключателя с разным весом: `rl-tabs` меняет содержимое области, `rl-seg`
выбирает одно значение из трёх-четырёх.

`rl-tabs` — вкладки разбора и разделов конфигурации. Активная помечена
`aria-selected="true"`: подчёркивание `accent-100` и текст `ink-100`, остальные —
`ink-300`. Порядок вкладок в разборе фиксирован и идёт от человеческого к машинному:
Сводка → Контекст JSON → Письмо → История. До семи вкладок; больше — это уже
навигация в сайдбаре.

`rl-seg` — короткий выбор внутри формы: как сильно мешает, за какой период,
какой режим. Состояние — `aria-pressed`. Никогда не используется как навигация и не
переключает содержимое страницы.

Что даёт потребитель: подписи, состояние и обработчики; для `rl-tabs` — роли
`tablist`/`tab`/`tabpanel` и связь через `aria-controls`.
