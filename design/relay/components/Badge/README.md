# Badge

Три разных знака в одном файле: статус репорта, severity от ИИ и чип контекста.

`rl-badge` — статус в жизни репорта, всегда со словом и точкой `rl-badge__dot`:
принят (нейтральный), в очереди (`--info`), анализируется (`--accent`), разобран
(`--ok`), нужен человек (`--warn`), сбой анализа (`--danger`). Шесть статусов —
закрытый список; новый статус заводится в системе, а не собирается на месте.

`rl-sev` — оценка ИИ: моноширинная, в рамке своего цвета, строчными латиницей
(`critical`, `high`, `medium`, `low`), потому что это машинное значение и оно едет в
JSON ровно так же. Цвет здесь вторичен — слово несёт смысл само.

`rl-chip` — кусок технического контекста, который приложение подставило само:
приложение, версия, экран, браузер. Подпись приглушена, значение в `<b>` — ярче.
Чип не кликается.

Что даёт потребитель: текст. Цвет не выбирается на глаз — он следует из статуса.
Не смешивать в одной строке бейдж статуса и severity без разделителя: они читаются
как одно значение.
