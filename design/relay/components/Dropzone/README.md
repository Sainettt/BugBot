# Dropzone

Приём вложений к репорту: скриншот, лог, PDF.

Пустая зона — пунктирная рамка `line-strong` на `surface-300`, иконка, строка
действия и строка ограничений (форматы и размер пишутся всегда). При перетаскивании
ставится `data-state="over"`: рамка и текст становятся акцентными, подложка —
`accent-soft`.

Загруженные файлы показываются списком `rl-file` под зоной, имя — моноширинно,
размер — приглушённо, кнопка удаления справа с `aria-label`. Превью картинок не
рисуем: имя файла достаточно, а картинка утяжеляет форму.

Зона доступна с клавиатуры (`tabindex="0"`) и всегда идёт в паре со скрытым
`<input type="file">` — перетаскивание не должно быть единственным способом.

Что даёт потребитель: обработчики drag/drop и выбора файла, список файлов, лимиты.
Ошибку по конкретному файлу показывать строкой `rl-hint--error` под списком, а не
подменять ею всю зону.
