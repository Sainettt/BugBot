# JsonPane

Результат работы модели: сводка словами сверху, машинный контекст снизу.

Главное правило системы: JSON никогда не первый. Сначала два-три предложения
обычным языком — что сломано, почему так выглядит для человека, где повторяется;
потом `rl-kv` с разобранными полями (компонент, похожие репорты, рекомендация,
уверенность); и только на вкладке «Контекст JSON» — сам объект. Админ должен
понять проблему, не открывая код.

Над кодом — строка с именем файла, расходом (`18 420 токенов · 6,4 с`) и кнопкой
«Скачать»: файл отдаётся как есть, тем же, что ушёл в письмо.

Подсветка — пять классов внутри `rl-code`: `.k` ключ (`info-100`), `.s` строка
(`accent-100`), `.n` число (`warn-100`), `.b` булево и `null` (`danger-100`), `.p`
скобки и запятые (`ink-300`). Разметка ставится на сервере; клиентских
подсветчиков в систему не тянем.

Уверенность ниже 0,5 — это `rl-callout--warn` над сводкой и статус «Нужен человек»,
а не мелкая цифра в списке полей.

Что даёт потребитель: текст сводки, поля разбора, подсвеченный JSON, ссылку на
файл. Длинный JSON скроллится внутри `rl-code`, страница под ним не растёт.
