# Field

Пара «подпись — контрол — подсказка»: единственный способ спросить что-то у человека.

Подпись всегда видима и связана с контролом через `for`/`id`; плейсхолдер вместо
подписи не используется. Необязательность помечается словом в `<span>` внутри
`rl-label`, а не звёздочкой.

Подсказка `rl-hint` живёт под полем постоянно и объясняет, что писать. Ошибка не
добавляет вторую строку, а заменяет подсказку на `rl-hint--error` и ставит на
обёртку `data-state="error"` — рамка поля становится `danger-100`. Цвет рамки никогда
не единственный признак ошибки: текст обязателен.

`rl-input--mono` / `rl-textarea--mono` — для машинных значений: ключей, доменов,
идентификаторов, шаблона промпта. Счётчик символов `rl-counter` — только там, где
лимит реально режет (описание проблемы, тема письма).

Что даёт потребитель: `id`, `name`, значение, обработчики, `readonly`/`disabled`,
текст подсказки и ошибки. Фокус рисует сам контрол кольцом `focus-ring` — не
перекрывать его своим `outline: none`.
