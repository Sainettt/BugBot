# Panel

Прямоугольник `surface-200` с волосяной рамкой `line-soft` — контейнер всего, что
не таблица.

Три необязательных слоя: `rl-panel__head` (заголовок слева, статус или одно
действие справа), `rl-panel__body` (отступ `space-5`) и `rl-panel__foot` (поясняющий
текст слева, действие справа). Заголовок — `rl-panel__title`, без иконки.

`rl-panel--raised` добавляет `shadow-panel`. Тень — признак того, что блок лежит
над страницей: публичная форма репорта, карточка разбора. Внутри админки панели
плоские, их держит рамка. Двух уровней теней на одном экране не бывает.

`rl-panel__body--flush` снимает отступ — для таблицы и списка во всю ширину панели.

Что даёт потребитель: содержимое тела, заголовок, действие в шапке. Пара
«ключ — значение» внутри тела собирается через `rl-kv` (`<dl>`/`<dt>`/`<dd>`).

Не делать: вложенные панели (вместо этого `rl-sep` и подзаголовок); цветную
заливку панели под статус — цвет несут бейджи и колауты.
