# Button

Действие в один клик: отправка отчёта, сохранение конфига, открытие разбора.

На экране ровно одна кнопка `rl-btn--primary` — та, ради которой экран открыли. Всё
остальное — `rl-btn` (обычная), `rl-btn--ghost` (прозрачная, в панельных шапках) или
`rl-btn--quiet` (без рамки, для третьестепенных действий в строке таблицы).

`rl-btn--danger` — только для необратимого: удалить проект, отозвать ключ. Рисуется
рамкой `danger-100`, а не заливкой: заливка красным на тёмном фоне слишком кричит.

Размеры: `--sm` в плотных местах (фильтры, строки таблицы), обычный в формах и шапках,
`--lg` — единственная кнопка отправки на публичной форме репорта, вместе с `--block`.

Что даёт потребитель: текст кнопки, `type`, обработчик, при необходимости `disabled`
и inline-SVG 14×14 первым ребёнком. Состояние загрузки — свой текст («Отправляем…»)
плюс `disabled`, спиннеров в системе нет.

Не делать: две primary рядом; кнопку-иконку без `aria-label`; красную заливку;
кнопку шириной во всю панель где-либо кроме публичной формы.
