# Switch

Включатель настройки, которая действует сразу, без кнопки «Сохранить».

Состояние задаётся `data-state="on|off"` на обёртке и дублируется в
`role="switch"` + `aria-checked`. Включённое положение — заливка `accent-100`,
выключенное — `surface-400` с рамкой `line-strong`; этой пары хватает и в светлой
теме, но подпись рядом обязательна, потому что позиция ручки — единственный
геометрический признак.

Строка настройки — название (13px, 600) и одно предложение объяснения `ink-300`
слева, переключатель справа, между строками `rl-sep`. Формулировка всегда
утвердительная: «Автоматический анализ», не «Не анализировать автоматически».

Для выбора из нескольких значений нужен `rl-seg` или селект, не ряд переключателей.
Если настройка применяется только после сохранения формы — это чекбокс, а не switch.

Что даёт потребитель: название, описание, состояние, обработчик клика и клавиш
Space/Enter.
