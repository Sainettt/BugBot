# StatTile

Плитка показателя и шкала расхода — верхняя строка админки.

Три части сверху вниз: капс-подпись `ink-300`, число моноширинным `t-metric` и
сноска с тем, с чем это число сравнивают («Вчера — 11», «≈ 23k на репорт»). Число
без сноски бесполезно: одна цифра ничего не говорит.

Цвет числа по умолчанию — `ink-100`. `--accent` берёт только показатель, ради
которого систему поставили (доля автоматических разборов), `--danger` — только
сбои, и только когда их больше нуля. Больше двух цветных плиток в ряду не бывает.

Ряд — четыре плитки: объём, результат, сбои, стоимость. Этого набора хватает; пятая
плитка означает, что показатель выбран неверно.

`rl-meter` — доля от лимита. Заливка `accent-100`, с 70% — `--warn`, с 90% —
`--danger`; рядом всегда подпись с абсолютными числами, потому что по одной полоске
лимит не прочитать.

Что даёт потребитель: подписи, значения, ширину заливки в процентах. Числа
форматировать с неразрывным пробелом между разрядами.
