# DataTable

Список репортов и предложений: главный рабочий экран админа.

Шапка таблицы — капс 11px `ink-300` на `surface-000`, липкая при прокрутке. Строка
живёт внутри `rl-panel` с `rl-panel__body--flush`, разделители — `line-soft`.

Первая колонка несёт две строки: заголовок репорта обычным текстом и мета-строку
(идентификатор `rl-id` моноширинно акцентом, автор) — 12px `ink-300`. Остальные
колонки одно-строчные.

Числовые колонки (`rl-num`) — моноширинные и выключены вправо, чтобы разряды
токенов и время сравнивались взглядом. Пустое значение — тире, не ноль и не пусто:
у неразобранного репорта токенов нет, и это видно.

Строка целиком кликабельна и открывает разбор; выбранная помечается
`aria-selected="true"` — подсветка `surface-400` плюс акцентная полоса слева.
Ховер — `surface-400`. Чересстрочной заливки нет.

Что даёт потребитель: данные, сортировку, обработчик клика по строке. Пустое
состояние — строка на всю ширину с текстом `ink-300`, а не пустая панель.
